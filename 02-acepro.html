Descripción

La Acepro AE403 es una guitarra eléctrica de estilo moderno. En este proyecto se presenta como una opción para estudiantes y músicos que buscan conocer diferentes formas y configuraciones de guitarra.

Características principales

  • Cuerpo eléctrico
  • Diseño moderno
  • Adecuada para práctica
  • Puede utilizarse en diferentes géneros

Lista ordenada de preparación

  1. Elegir la guitarra.
  2. Revisar las cuerdas.
  3. Conectar el cable.
  4. Conectar el amplificador.
  5. Encender el equipo.
